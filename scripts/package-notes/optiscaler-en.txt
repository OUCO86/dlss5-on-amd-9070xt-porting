OptiScaler-DLSS5-AMD @VERSION@ — standard full game package

1. Inputs above 1080p are no longer rejected (DLSS5_FIT_LARGE=1, on by default): a render resolution beyond 1920x1080 is fitted (downsampled) onto the 1080 tier for the network, and the original-resolution frame is then composed the way the original codec does it (the full-resolution picture is the base, the network output steers luminance/colour); it is not a plain upscale. Stellar Blade at 2560x1440 Native AA measured 44 fps. Ultrawide takes the same path (letterboxed network surface) but has not been tested on hardware; feedback welcome.
2. Six bit-exact kernel improvements since 0.28: LDS-scoped workgroup fences, folded C32 FFN, C32 byte chain with vectorised input staging, register-resident multi-head attention, C32 in16 aliasing (LDS residency), transposed FFN tail. About -7% whole-network time; Stellar Blade 900p simple scenes reach ~60 fps. Output is bit-identical to 0.28.
The regular OptiScaler framework retains the 0.27 baseline; this is not the RE9 host.

Exit the game, back up existing mod files, and extract ALL files beside the actual game executable (often Binaries/Win64). Select DLSS input in the game; OptiScaler routes it to FSR. Supported integration is low-resolution rendering → DLSS5 → FSR → display. Neural input is no longer size-limited: up to 1080p it uses the smallest fitting tier (720/900/1080); above 1080p it is fitted onto the 1080 tier and restored (DLSS5_FIT_LARGE=1). F6 toggles NR; Insert opens OptiScaler; Home opens ReShade.

DLSS5-AMD/native-game-flags.txt uses the repository standard template and NETWORK_HEIGHT=auto. Existing block skips remain; lossy adaptive reuse is disabled. Optional reuse requires DLSS5_VIT_ADAPTIVE=1, DLSS5_VIT_REUSE_HOTKEY=1, DLSS5_HIP_GRAPH=0 and DLSS5_HIP_VIT_BYTE_STREAM=0, then restart; F8 switches reuse/full computation. DLSS5_SHOW_FPS and DLSS5_NOTICE control the corresponding information.

Use this route for existing supported games such as Stellar Blade and Lies of P. RE9 uses the separate REFramework package; do not mix the two hosts/runtimes. Avoid simultaneously processing the same game through Magpie.

Full model and gfx1200/gfx1201 modules included. Requires AMD driver HIP7 (amdhip64_7.dll); RX9070XT tested, gfx1200 hardware feedback still needed. Verify files with SHA256SUMS.txt. Framework and third-party licenses remain included.
