Cyberpunk 2077 with no configuration: the bundled OptiScaler.ini carries [Inputs] EnableFfxInputs=false (needed by games that ship their own FSR dll; a no-op for Stellar Blade); DLSS5_PRE_UPSCALE_ASYNC=auto and DLSS5_STRENGTH=auto look the game executable up in a table -- Cyberpunk gets synchronous submission and luminance-only transfer (1,0): the pre-upscale route hands the network the linear colour buffer before the game's tone mapper, and taking the network's hue there and running it through the game's LUT turned green neon ambient brown; luminance-only keeps the detail gain with the game's own colours. Other titles 1,1.
4. Fix: neural processing vanished after switching the DLSS preset/resolution in-game (the add-on pinned itself to the first FSR context; when the host destroyed it through the shim the pin never cleared and every later dispatch passed through silently; eight resolution changes also exhausted the restart budget). The shim-level destroy is now hooked too, a pinned context that stops dispatching is dropped, and only failed sessions spend the restart budget.
Measured (RX 9070 XT, over Splashtop): Stellar Blade 900p->2K simple scene 60-61 fps, 1080p->2K 47-48; Cyberpunk 2077 low settings balanced 51-52, quality 41.
The regular OptiScaler framework retains the 0.27 baseline; this is not the RE9 host.

Exit the game, back up existing mod files, and extract ALL files beside the actual game executable (often Binaries/Win64). Select DLSS input in the game; OptiScaler routes it to FSR. Supported integration is low-resolution rendering → DLSS5 → FSR → display. Neural input is no longer size-limited: up to 1080p it uses the smallest fitting tier (720/900/1080); above 1080p it is fitted onto the 1080 tier and restored (DLSS5_FIT_LARGE=1). F6 toggles NR; Insert opens OptiScaler; Home opens ReShade.

DLSS5-AMD/native-game-flags.txt uses the repository standard template and NETWORK_HEIGHT=auto. Existing block skips remain; lossy adaptive reuse is disabled. Optional reuse requires DLSS5_VIT_ADAPTIVE=1, DLSS5_VIT_REUSE_HOTKEY=1, DLSS5_HIP_GRAPH=0 and DLSS5_HIP_VIT_BYTE_STREAM=0, then restart; F8 switches reuse/full computation. DLSS5_SHOW_FPS and DLSS5_NOTICE control the corresponding information.

Use this route for existing supported games such as Stellar Blade, Lies of P and Cyberpunk 2077 (2.31, no configuration). RE9 uses the separate REFramework package; do not mix the two hosts/runtimes. Avoid simultaneously processing the same game through Magpie.

Full model and gfx1200/gfx1201 modules included. Requires AMD driver HIP7 (amdhip64_7.dll); RX9070XT tested, gfx1200 hardware feedback still needed. Verify files with SHA256SUMS.txt. Framework and third-party licenses remain included.
