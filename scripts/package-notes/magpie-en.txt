Magpie-DLSS5-AMD @VERSION@ — full portable package

1. Chain launches submitted any-order with per-tile flags (DLSS5_HIP_PDL=1, on by default): the FFN and attention kernels of the C64/C128/C256 blocks no longer wait for the previous launch to drain; the dependency moves into the kernels. Output bit-identical; about -1.6% whole-network time at 900p.
2. FFN full-line stores (bit-exact, about -0.6%). 0.29 -> 0.30 kernel output is bit-identical.
Magpie framework/pipeline retain the verified 0.27 baseline.

Extract everything into a separate directory and run Magpie.exe. Windows up to 1920x1080 use the smallest fitting tier; larger windows are fitted onto the 1080 tier and restored (DLSS5_FIT_LARGE=1). The bundled chain is FSR3_SR (DLSS5 entry, 1x input size) → FSR4 upscale → XeSS frame generation. Alt+Shift+A starts/stops scaling; F6 toggles neural rendering. Use AMDOF only at the first stage; None for the later FSR4/XeSS stages.

DLSS5-AMD/native-game-flags.txt is the tracked Magpie configuration. NETWORK_HEIGHT=auto chooses720/900/1080. Existing default block skips remain; adaptive reuse is off. F8 requires explicitly enabling the reuse hotkey. Set both DLSS5_SHOW_FPS=0 and DLSS5_NOTICE=0 to disable the corresponding information.

Includes full model, matched add-on/shaders, and24 modules per gfx1200/gfx1201 architecture. Requires an AMD driver providing amdhip64_7.dll. RX9070XT tested; gfx1200 hardware feedback is still needed. This is not a patch.

Magpie.exe/framework DLLs are the host; dlss5-amd.addon64 is our integration; DLSS5-AMD/native-game-tiled-assets holds models/shaders/HIP modules. See SHA256SUMS.txt and component licenses.
