# Extend exact-zero vertical padding guards to C64 and C256

Baseline is147421f, which already includes the adopted C128 guard. `prepare.py` pins that source and emits separate c64 and c256 variants by changing only the compile-time channel predicate. Same original16-row workgroup geometry,128threads forC64 and512 forC256. The workgroup-uniform top/bottom padding test and complete feature+normalized-QKV zero stores are unchanged. This is exact for the existing finite, bias-free model and canonical-zero conversion; the later attention computation is not skipped.

Build `/tmp/mh-empty-tile/pure.cpp` with MinGW -std=c++17 -O2 -static -D_WIN32_WINNT=0x0A00 as pure_mh_empty.exe. It instruments the first kernel named by DLSS5_EMPTY_TARGET,2000warmup/10000measured launches, ordinary HIP wall/sync; the full rawFP32 network result is checked first/final and an unreached target is an error. C64 targets its mapped byte-input entry; C256 targets the fragment-packed mapped byte-input entry. No host dispatch or weight ABI changes.

Upload emitted variants as hip-backend/mh-empty-{c64,c256}.hip. `build.ps1 -Variant ...` copies the frozen C128-improved module set and builds gfx1200/gfx1201. `time-kernel.ps1` compares the requested variant against that same baseline in ABBA. The normal replay still uses benchmark_main_reuse.exe. `run.ps1 -Variant ...` validates48paired static/moving900/1080 RGB frames then160frameABBA; -TimingFrames1000 uses longABBA/discard200, and -ExtraControls adds720/history/f32input/f32feature routes. All GPU scripts guard known games/Magpie. Runtime GPU is gfx1201 only.

`collect.ps1` archives only small logs/CSV/flags/hashes. `analyze.py <evidence> --basic-only` expects48RGB pairs, without the four extra cases; omit it for96pairs, or explicitly use --kernel-only for an isolated rejected probe. The baseline is the preceding main, not the older pre-C128 modules. Report/decision: Development/results/mh-empty-tile-20260921/report.md.

Outcome: C256-only extension adopted after96paired RGB frames,8raw FP32 comparisons, dual-arch compile and1000frameABBA. C64 passes48RGB pairs and8raw comparisons, but its1080 whole-network short/long tests show no positive gain; it is not adopted. No combined candidate was built/tested. The production source was checked against the tested C256 source exactly after stripping build defines. Game installations and release archives remain unchanged.
