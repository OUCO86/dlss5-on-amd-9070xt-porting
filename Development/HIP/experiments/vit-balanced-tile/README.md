# ViT 32×32平衡tile：有效重用与算力缺口

基线cdfd6b6，生产ViT展开K1024/N4096；同样4个16×16累加片段，16×64的A1/B4改为32×32的A2/B2。M640时wave数/计算量/累加器数不变，逻辑载荷从每K16的1280字节降至1024；M400最后16行单独BM1模板，避免越界与无用矩阵计算（wave数多4%）。

候选：固定尺寸原形状control、平衡u4、平衡u1、平衡列优先u4。所有输出保持K次序和原激活/FP8舍入。真实block31输入/权重；每槽反码填充后先完整比较再预热/计时，末尾再次比较。900/1080各两轮ABBA，约100ms预热+400ms计时/槽；只读ADL遥测，先1080后900，不锁频。

双架构编译，只gfx1201实跑。需核对ISA加载/MMA数、寄存器/scratch和运行时驻留上限；不把源码逻辑读取当DRAM流量。如果微核有收益，再做整网替换/回归；失败也记录其对算力缺口的约束。实验模块隔离，不部署游戏/发布包。

## 已完成

第一批64微槽；第二批80槽交叉A布局/形状及打包成本；最后16槽整网、3200计时帧。所有输出检查通过。平衡行布局明显变慢，片段A可消除其大部分惩罚，但整网没有稳定收益，不采用。完整结论见../../../results/vit-balanced-tile-20260922/README.md。prepare-layout.py在prepare.py之后执行；prepare-network.py生成完整网络替换host；build-layout/run-layout/run-network/collect分别负责双架构构建、测量与归档。
