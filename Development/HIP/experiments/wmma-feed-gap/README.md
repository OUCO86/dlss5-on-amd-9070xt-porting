# 算力缺口：累加依赖还是供数路径？

本实验只解释缺口，不产生生产优化。318.md是主线锚点：先列竞争解释与能区分它们的对照，再看数据，禁止把“候选快一点”替代机制认识。

## 竞争解释与预测（实验前）

1. 四条累加链/真实工作规模本身限制约150TF：在相同256条WMMA/wave、2560wave下，即使操作数常驻寄存器也难接近同频参考；增加独立累加链可能明显提高吞吐。
2. 逐轮供数及地址/等待/调度是主要限制：相同四链、矩阵数、工作规模，寄存器组明显更快；逐轮加载组变慢。
3. 供数限制主要来自访问工作集与复用：同一volatile加载核（每K16五条64位向量加载）只将A/B运行时步长设0或16，冻结地址显著加快。若冻结仍慢、寄存器快，则仅减少访问范围不够，进一步调查加载指令发射、操作数依赖和调度。

上面是预测，不是结论。链数变化同时改变寄存器/驻留容量；寄存器与加载核也不只差内存周期。实验用于找主导候选，不能简单相减分配所有周期。

## 对照约束（初始设计）

- 对齐ViT展开的M640/N4096/K1024：2560wave，每wave256条FP8 WMMA，共5.36870912GFLOP；另测M400/1600wave作为复核。
- 每循环16条WMMA，16轮；resident1/2/4/8/16改变依赖链数，总指令数不变。
- feed4用A原行布局/B原片段布局；volatile固定加载避免冻结地址后编译器将读取移出循环。plain4对照检查volatile自身的扰动；必须先审ISA实际加载数量/宽度。
- 输入全部FP8 1/16，累加初值按链不同，结果为精确二进制分数，每lane所有累加器都进入校验和。冻结地址保持数学值不变。不是实际模型数据，不替代整网归因。
- 所有版本同样写每lane一个校验和，省去原激活/FP8输出，已知固定差异；与约36μs真实核比较仅作量级锚点，不能当严格消融差。
- 无短GPU事件，批量host wall+sync，两轮ABBA，每槽预热约100ms/计时约400ms；只读ADL，不改频率/功耗。

接受判据：输出、生成指令/资源、配对时钟都记录。若结果不能区分假说，就承认本轮没有解释，不换成优化成果。

## 校准后的正式设计与复现

初版kernel-pilot.hip / bench-pilot.cpp使用运行时步长及volatile。ISA显示volatile被编译为SCOPE_SYS flat_load且逐次wait，不能作为正常读取证据，640/400两目录仅保留校准。普通步长也增加地址指令；第二版改成model4（固定K步长）及masked4（运行时k & mask）。masked4固定20条global_load_b64+16条WMMA/循环，只改遮罩，不改机器码。A/B mask为1023时遍历全部K，为0（或15，k本身为16倍数）时反复同址；checksum不变。

第二版bench-cold.cpp对应bench-masked.exe，masked-640/400再次暴露独立微测显存约190MHz。不能把该状态与正常网络对比。bench-conditioned.cpp加入前序64MiB D2D搬运，每槽开始约200ms，每个计时chunk前约2ms；搬运完成后才计时，10个chunk合计约400ms。每次copy后显式hipDeviceSynchronize，避免把异步排队时间当搬运完成时间。首次未显式等待的调理程序被停止，尚未生成计时槽，不采信；修正后所有正式槽完成。调理改变缓存/频率状态，不是生产提速方案。

正式conditioned-640/400的时钟只关联chunks.csv中的计时区间，排除搬运区间；200ms ADL仍是粗采样，不是逐周期数据。最后bench.cpp / bench-sweep.exe在相同masked4机器码上扫描B span16/32/64/128/256/512/1024（A保持完整），即权重逻辑访问集合64KiB至4MiB，矩阵数量/加载数量不变。最后一组full对full校准漂移。结果sweep-640。

四个host源都用MinGW C++17/O2/static直接编译；新kernel.hip通过build.ps1生成masked-gfx1200/gfx1201，旧kernel-pilot.hip对应gfx1200/gfx1201。run.ps1及-Conditioned跑第二/三批，run-sweep.ps1跑工作集扫描。collect.ps1归档，analyze.py检查CSV/分chunk计时/输出并分析ISA；resources.cpp只查询NUM_REGS与驻留上限，不执行kernel。所有宿主只操作D:\DLSSNR-Lab\hip-backend\wmma-feed-gap实验目录。
