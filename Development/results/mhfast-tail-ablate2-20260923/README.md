## 读法

转置拿走的是 LDS 写和输出写；归一化交换本身（两个 barrier + 128 线程串行 32 项求和）还值 1.5%，其中串行求和 0.8%、barrier 与 LDS 往返 0.7%。这是 1b（非逐位）的上界，超过 0.5% 的门槛，值得做。

1b 的形状：part 0/1 各由 C/32 个 wave 承担，每 wave 持一个 head 的 32 列（2 个列 tile × 16 k = 32 WMMA，加 part 2 的 16 = 48，与现在相同）；转置布局下一行的 32 列落在 2 个 lane × 2 个 tile 上，平方和 = lane 内 16 项顺序求和 + 一次 lane^16 permute，rsqrt 与 scale 在寄存器里完成，无 LDS 无 barrier。求和从 32 项顺序变为两个 16 项部分和相加——只在 rsqrt 之前重结合，fp8 输出偶有单位翻转，需用户看画质。

证据：1080/、900/ 下 network.csv、run.log、telemetry.log；summary.txt；console.log。工具 HIP/experiments/mhfast-tail-ablate2。
