## 读法与限制

- 区段时间含数据搬运、区段内 launch/排队与全部运算，不是纯 ALU 时间；族含相邻上下采样（C32 含输入融合、两条半分辨率链与 post/RGB）。
- 各区段来自不同帧的配对差，不是同一帧内的时间戳；区段和比 GPU 跨度高 1.2～1.8%，小区段（transitions）不宜精细排序，PDL0 900 的 transitions 0.026ms 属噪声量级。
- PDL 下标记事件会在切点处加一次隐式等待，可能改变相邻两族的重叠；控制显示整帧扰动很小，但单个边界上的重叠归属仍有 ±0.1ms 级不确定性。
- 输入是固定帧、无时序历史；游戏内比例会随场景与历史路径略有不同。

## 判断

变化最大：C64/C128/C256 各降 0.4～0.5ms（1080，约 −20%），C32 降 1.2ms 但份额仍 34%——wave-owned 同比例缩小了它，没有改变排位。**C512 是唯一没动的族**（2.18→2.23ms），份额由 12.0% 升到 14.5%（900 为 16.4%，已是第二大），92 次派发与 09-21 相同。

**下一刀推荐 C512**：它是唯一还没做"一头一 wave"结构改造的注意力族，同一改造在 C64/C128 上兑现了约 20% 的区段时间；Daniel 0.4.0 也为 C512/ViT 新增了 reg1d 与 512 布局转换核。按同比例估，1080 可省约 0.4～0.5ms。C32 虽仍最大（5.24ms），但已整链单 wave，剩下的是输入准备与 FFN 主体（见 c32-phase-current），需要另一类机制，排第二。
