## 观测

以下为按各 launch 实际 wave 数加权的**插桩 wave 区间/整段周期比**，不是整网帧时占比，也不是可回收百分比。

| 区间 | 900 | 1080 |
|---|---:|---:|
| 输入准备 | 23.8% | 23.9% |
| FFN（含入口同步、残差与发布） | 38.2% | 38.1% |
| QKV + 归一化 | 13.0% | 12.9% |
| 注意力 + 发布 | 11.2% | 11.2% |
| 投影/输出路径 | 5.5% | 5.5% |
| Finish / RGB 尾部 | 8.5% | 8.5% |

FFN 独立细分（换用 `(frame*5)%32` 采样余数，同时重测 whole/staging/ffn）：

| FFN 子区间 | 900 | 1080 |
|---|---:|---:|
| 入口原同步 | 2.6% | 2.7% |
| 残差初始化 | 3.9% | 4.0% |
| 展开 + 激活 + 收缩主体 | 25.1% | 25.1% |
| FFN 结果转换/写出/原同步 | 6.8% | 6.8% |

重采样的输入准备均约23.7%，FFN整体约38.1～38.2%，热点排序稳定。新 FFN 口径包含发布与同步，不能直接拿它的38%减旧文的26%宣称瓶颈增长了12个百分点。

FFN主体的25%还包含权重读取、激活与FP8转换，不是纯WMMA算术份额。

## 按核看，更具体

- raw chain 输入准备约3200周期，FFN主体约7500周期，FFN发布约2400周期；继续抠 post 的几条输入读取没有打中这些核的大头。
- mapped 核输入准备约6500～6700周期，FFN主体约6900周期，两边都贵。
- prefix_finish 的输入准备约9500周期，但包含输入特征/噪声生成和 prefix 投影，不能全叫“搬运”。
- post70 输入准备约7900周期，FFN主体约5900周期；其输入仍值得研究，但前轮重复读/FP16局部改法已经无收益。
- 非 Finish / 非 RGB 核的空尾部约18周期，可作计时边界开销的量级参考。

## 扰动与验证

- 计时指令实为本地 `s_getreg_b32 hwreg(29,0,20)`，无 REALTIME 消息；部分核的 `MSG_DEALLOC_VGPRS` 属正常寄存器释放。
- 粗分插桩整帧约增加0.07～0.14ms；FFN细分约0.05～0.13ms，均在本次基线的1%内。正常基线仍约900 11.6ms、1080 16.7ms。
- 原核10个函数体与prod8机器码全同。插桩无private spill、LDS源码未增加，但不是零影响：chain VGPR151→174，chain_finish153→176，mapped169→174，prefix152不变，post158→156；SGPR/调度也会变。因此只把稳定排序当选刀依据，不宣称已得到未插桩精确分账。
- 每阶段先ABBA检查扰动，再8帧逐帧RGB检查；每条样本校验magic、窗口编号、样本数量、阶段周期不超过整段。20位计数器按模相减，短区间假设仍存在，不用它解释极长停顿。
- 第一轮采样余数0/4/…/28；第二轮0/5/10/15/20/25/30/3，减少固定低位抽样偏差。首帧位置相同但其余帧不同，结果没有翻转热点排序。
