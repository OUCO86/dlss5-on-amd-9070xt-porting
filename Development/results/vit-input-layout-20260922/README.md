# ViT输入连续布局：小幅单核变化，没有整网收益

基线b1be848，实际推理为固定尺寸优化后的main。研究问题：此前共享输入地址的交错收益，能否通过把单份A操作数改为片段连续布局兑现？本轮不改生产。

## 对照设计

默认行布局的A片段，前16lane读取地址步长1024字节；片段布局按16行×32列一块512字节排列，一次A加载的32lane连续覆盖256字节。B仍使用现有原生片段权重布局。两边都把K1024/N4096常量传给编译器，保持同一K累加、激活和FP8输出。

使用现有vit_pack_input_tiled，并增加固定尺寸probe_vit_tiled_fixed；原动态尺寸vit_expand_blocked_fp8_frag_tiledin只作负控制。host在真实block31截取打包前FP32输入；先验证打包后的字节置换（CPU从原行布局参考构造expected），再逐字节比较矩阵输出。每个计时槽前反码填充并预检，后面再次完整检查。

分别测矩阵、打包、打包+矩阵顺序组合；各自两轮ABBA，约100ms预热/400ms批计时，host wall+sync，没有密集逐核event。单独打包的最大40000次上限使个别批次只有约80～110ms，ADL200ms采样可能没有命中（900行打包为null），不补造时钟。

## 单核与组合结果

| 阶段 | 900行→片段 μs | 1080行→片段 μs |
|---|---:|---:|
| 固定尺寸矩阵 | 24.703→24.750（+0.19%） | 35.643→34.855（-2.21%） |
| 输入打包 | 1.942→2.417（+24.48%） | 2.241→2.721（+21.46%） |
| 打包+矩阵同序列 | 26.270→26.669（+1.52%） | 38.941→37.871（-2.75%） |
| 固定行矩阵→旧动态尺寸片段矩阵 | 24.887→28.954（+16.34%） | 36.052→40.799（+13.17%） |

各阶段独立预热计时，不能把单项均值相加冒充组合，也不能把组合微基准直接乘八当成整网变化。打包仍是一遍转换，没有额外插入独立转置；只是输出排列更复杂。

1080矩阵核心中位2454.5→2481.5MHz、显存均2238，约2%的变化含运行频率因素。组合核心2529→2535.5MHz、显存均2238。900矩阵核心2608→2620、显存均1538；组合显存均2238。记录状态而不将它当严格锁频实验。

ISA：固定行/片段矩阵77/76 VGPR，LDS0、scratch0、编译器Occupancy16；两者已展开K循环。动态片段48VGPR仍短循环，更慢，说明旧的动态尺寸对照不能用来隔离布局收益。打包7→10VGPR，其余资源不变。静态指令表含通用fallback，不直接当执行次数。

## 整网验收

实验host每帧将八次pack和八次expand同时切换，其余路径相同。每档8槽ABBA，每槽40预热+200计时，3200计时帧；候选每槽核实3200次替换，逐槽最终原始FP32与黄金输出一致。

| 档位 | 行布局ms | 片段布局ms | 差ms |
|---|---:|---:|---:|
| 900 | 12.742735 | 12.741888 | -0.000848 |
| 1080 | 17.917179 | 17.915888 | -0.001291 |

约1μs的差远小于槽位漂移，视为持平，不采用。配对整网核心900为2753→2752MHz、1080为2725→2726.5，显存均2505MHz。

## 对算力缺口的意义

这次布局更换没有填上主要缺口。它不等于“访存已被排除”：共享同一输入增加数据重用，片段连续排列改善地址组织，两者不是同一件事；缓存容量、读指令吞吐、依赖等待仍未分清。看起来分散的地址也不等于每次都从显存重新取数。

给下一轮一个可核对的工作量基准：现有M1每K16步骤读取A一份、B四份，每份32lane×8字节，共1280字节逻辑操作数；四条16×16×16 WMMA共32768FLOPs，即25.6 FLOPs/逻辑字节。1080矩阵全程约200MiB逻辑A/B读取，包含反复访问。它不是DRAM流量，不能和显存标称带宽直接比。

下一轮固定这部分逻辑读取量，让寄存器内片段执行额外矩阵运算，观察计算密度增加时吞吐曲线。必须核对编译后的矩阵/读取指令，防止额外工作被消除，并量N=1探针扰动；输出保持参考结果，不把冗余诊断计算当生产有效FLOPs或把重复增量直接作原生耗时分解。

## 验证和归档

64个分项槽预/后完整比较均同，两个微基准进程首尾4次原始FP32同；整网16槽逐槽原始FP32同，共20次原始网络检查。两个架构编译，实跑gfx1201。CSV/遥测/ISA资源/hash/summary都保留，无生产、游戏或发布包改动。
