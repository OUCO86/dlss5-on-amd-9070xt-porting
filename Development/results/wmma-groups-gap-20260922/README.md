# 算力缺口：任务分组与编号映射改变供数，但整网分账尚未闭合

2026-09-22，gfx1201实跑、双架构编译。本轮固定M640/N4096/K1024、2560wave、数学工作和地址集合，区分工作组组织与任务到派发编号的映射。无生产改动。

## 固定总wave数，合组反而更慢

每组W=1/2/4/8个wave，对应32/64/128/256线程、2560/W个组。i映射令组内相邻列块共享A；m映射令相邻行块共享B。每wave每轮仍10条128位读取，矩阵版16条WMMA，读取版20条独立XOR链，均16轮。不同入口的前缀地址计算有差异，不宣称整个汇编相同。

同进程固定A640KiB/B4MiB地址，计时外D2D调理，两轮ABBA、10个chunk约400ms；只读时钟，不修改配置。先对旧入口校准，再作以下配对：

| 矩阵对照 | 基线→改变 μs |
|---|---:|
| i1→i2 | 29.540→42.952 |
| i1→i4 | 29.476→43.517 |
| i1→i8 | 29.369→46.901 |
| i2→m2 | 42.858→44.544 |
| i4→m4 | 43.534→45.812 |
| i8→m8 | 46.949→46.664 |

相邻行映射没有恢复原W1表现。原始14个入口的HIP容量均为64wave/MP，组数上限随W反比变化；动态驻留未知，静态容量不足以解释时间。

再用 `readfirstlane` 显式表达wave内编号一致，mat_i2寄存器76→75，42.911→42.851μs，慢点仍在。不能把多一个寄存器当解释，也不能仅归给编译器没识别编号一致性。

14个原始导出入口均通过非均匀FP8 CPU参考与canary检查；每入口一个工作组，活动lane校验和正确，其余输出保持哨兵。不是完整矩阵逐元素检查。CPU还穷举全网格映射，确认2560wave无漏无重。

## 固定W1与组数，只置换任务编号

同一入口用 `logical_wave=(group*stride)%2560`，stride1/17/63/129都是双射。每个逻辑任务仍取原地址、写原位置，改变的是任务到派发编号的映射，不保证硬件按编号执行。编号入口先对旧i1校准；正式不同stride共用机器码。

| stride1→改变 | 矩阵 μs | 读取多链 μs |
|---|---:|---:|
| 17 | 29.456→40.719 | 37.666→38.736 |
| 63 | 29.343→40.618 | 37.732→39.120 |
| 129 | 29.449→40.716 | 37.780→37.924 |

矩阵版明显变慢，读取版变化较小。非均匀参考与canary覆盖置换后的输出位置，数学任务没有变。结果支持任务映射影响重用及请求服务过程，但具体由何种并发关系造成，仍需动态证据。

## 计数器支持局部解释，也留下不一致

各RGP捕获为独立热重复、64次dispatch，均有167936000个L0请求。order1→129的L0命中率35.319%→26.345%，L2请求108789776→123859662，增加约13.85%；L2命中率仍99.961%/99.964%，busy cycles为5652364/6909883。

相同逻辑工作向L2发出更多请求，说明映射确实改变了缓存重用；但不能据此把13.85%兑换成耗时份额。捕获不等于原调理壁钟状态，也不是同频时间对照。

原分组捕获i1/i2/m2的L2请求为106002734/102002857/98478707，反而与独立wall快慢不一致；busy cycles为5580881/9065517/5715459。不能只留编号实验中方向一致的数据。请求总量、到达时序、并发与状态仍未拆开。

## 能解释多少缺口

目前不能给全网已解释比例。硬件寄存器峰值已验证；ViT编译调度对照解释了一对展开/收缩约20μs的差异；真实展开核供数背压、请求账本与局部重用已有证据。但它们不是可相加的独立时间分量，供数、计算和调度会重叠，周期分账尚未闭合。

历史整个ViT区段约为1.488/12.86=11.57%、2.471/18.30=13.50%的整网时间。当前展开样本只占其中部分，12～14%不能叫已解释比例，且这是历史不同测量口径下的尺度参考。C32此前约占35%，机制仍未解释完。

这里的“解释”已有因果对照支持，强于看到某个利用率低便猜瓶颈；但还弱于知道整网每一段等待多少周期。一个对照能否改变结果，与它解释了原运行多少时间，是两个不同问题。后续按整网权重安排调查，才能避免在局部现象上积累很多精细数字，却回答不了用户最初的问题。

下一步优先把请求账本与受控对照带回C32大头。ViT动态时序与原生份额仍可继续，但优先级下降；不再仅因小诊断核能观察到现象就无限追下去，也不将某个静态occupancy值当硬件排队结论。
